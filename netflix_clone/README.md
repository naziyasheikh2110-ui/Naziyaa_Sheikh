Netflix Clone (Frontend)

A static Netflix landing page clone built using HTML, CSS, and vanilla JavaScript.
This project focuses on layout, styling, responsiveness, and basic interactivity — not backend or authentication.

⚠️ This is a UI clone for learning purposes only. No real Netflix data, APIs, or accounts involved.

🚀 Live Demo

🛠️ Tech Stack

HTML5 – Page structure & semantic layout

CSS3 – Styling, layout, responsiveness

JavaScript (Vanilla) – Basic interactivity

Google Fonts – Montserrat & Roboto

No frameworks. No libraries. Just core frontend fundamentals.

✨ Features

Netflix-style hero section with background overlay

Trending movies row with horizontal scroll buttons

FAQ accordion (expand/collapse on click using JS)

Responsive layout for desktop, tablet, and mobile

Clean UI inspired by Netflix India

⚙️ JavaScript Functionality
1. Trending Movies Scroll

Left & right buttons scroll the movie row horizontally

Implemented using scrollLeft

2. FAQ Toggle

Clicking a question expands/collapses the answer

Uses class toggling (active) for smooth UX

This is simple, readable JS — good for beginners.

📱 Responsiveness

Desktop: Full layout with grid-based sections

Tablet: Adjusted font sizes & card layout

Mobile:

Stacked email input

Single-column reason cards

Optimized movie thumbnails

Handled purely with CSS media queries.


🎯 What This Project Demonstrates

Strong grip on HTML structure

Solid CSS layout & styling

Understanding of DOM manipulation

Ability to clone a real-world UI

Clean separation of concerns (HTML / CSS / JS)
