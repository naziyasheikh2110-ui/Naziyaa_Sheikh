# Simon Says Game 🎮

A simple and interactive **Simon Says memory game** built using **HTML, CSS, and JavaScript**.

## 🔹 About the Project
This is one of my first mini JavaScript projects where I practiced:
- DOM manipulation
- Event handling
- Game logic

The game generates a sequence of colors that the player must repeat in the correct order. With each level, the sequence becomes longer and more challenging.

## 🔹 Features
- Increasing difficulty with each level
- Visual feedback for user clicks
- Game over detection and restart option

## 🔹 Tech Stack
- HTML
- CSS
- JavaScript (Vanilla JS)

## 🔹 How to Play
1. Press any key to start the game
2. Watch the color sequence carefully
3. Click the colors in the same order
4. Try to reach the highest level possible!

## 🔹 What I Learned
- Managing game state using arrays
- Using callbacks and timing functions
- Structuring JavaScript code logically
